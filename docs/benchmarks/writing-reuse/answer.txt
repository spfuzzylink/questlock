Questlock v0.13.0 is out! We've closed issues 32, 33, and 34 with pull request 35, so you should find things a bit smoother. The budget stops now show diagnostic numbers, helping you understand usage and estimates – though they don’t automatically adjust limits or switch models.  The `questlock_status` tool is also available, giving you runtime version, request root, profile and policy details. Remember, broker and provider health are still marked as not checked, and the doctor distinguishes custom profiles from missing defaults. 

We still need to review factual support and suitability for any answers generated; the library doesn't automatically provide Codex or Claude chat credits.  Workflow writing continues to rely on approved references and word limits. Exact reuse requires an unchanged approved snapshot, matching runtime, and a valid reuse window. Let’s be sure to validate anything new before deploying it widely.
