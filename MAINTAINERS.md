The maintainer owns project direction, reviews, release decisions and security
coordination. An AI assistant, bot, review tool or contributor acknowledgement
does not grant maintainer status or repository permissions.

To contribute, start with [CONTRIBUTING.md](CONTRIBUTING.md). Maintainer changes
and decision-making are described in [GOVERNANCE.md](GOVERNANCE.md). Report
vulnerabilities through the private route in [SECURITY.md](SECURITY.md).
