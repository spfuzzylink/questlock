# Example personal preferences — opt in yourself

This is example text, not repository instructions or an automatically loaded
Questlock setting. Keep your edited copy in your own client instruction storage.

- Prefer checked literal edits and exact still-valid result reuse.
- For suitable bounded tasks, use my explicitly selected installed local model.
  Never silently add a paid fallback or purchase provider credits.
- Keep required facts and quality checks. If local output fails them, stop and
  let me decide; shorter or cheaper output does not establish correctness.
- Use my resource-admission configuration. Leave headroom for persistence and
  health checks; retain durable work when new admissions pause.
- Write in the voice I request for the task. Do not assume the upstream
  maintainer's preferred tone, branding, branch names or account limits.

These preferences do not change the model or allowance of an already-hosted
assistant chat. Live configuration changes still need native validation and
independent recovery; see the onboarding guide.
