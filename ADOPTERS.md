# Questlock adoption

This file distinguishes maintainer use and public validation from independently
confirmed external adoption. An entry does not imply endorsement of the
project or a guarantee about its performance.

## Maintainer use

The maintainer uses Questlock in real local development and writing workflows,
including bounded tasks, checked revisions and exact result reuse through MCP.
Reproducible observations and their limits are recorded in the
[validation history](docs/validation.md) and
[writing reuse report](docs/writing-reuse-success-report.md).

## External adopters

No external organization has yet supplied a public adopter entry for this
file. Repository stars, clones and release-asset downloads are discovery
signals; they are not a count of production deployments or accepted outcomes.

If you use Questlock and want to be listed, open a pull request with your name
or organization, a short description of the workflow, the version or deployment
context and a public reference if available. Confirm that you have permission
to publish the entry. Do not include private infrastructure details, credentials
or unmeasured savings claims.
